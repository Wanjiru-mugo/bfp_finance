# Invoices

Drop invoice and receipt PDFs here. Name each file exactly as the `invoice` field in data.json:

`YYYY-MM-DD-guest.pdf`, for example `2026-10-30-natalie.pdf`

For a second document on the same recording (e.g. hospitality), add a word: `2026-10-30-natalie-lunch.pdf`, and put that name in the entry's `invoice` field.
